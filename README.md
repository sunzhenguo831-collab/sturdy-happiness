# sturdy-happiness我的第一个仓库

## 每天一点 · 零基础英语复习

一个无需安装、无需登录、无需联网或付费接口的英语拼写练习网页。

包含 egg（鸡蛋）、rice（米饭）、water（水）、tea（茶）、coffee（咖啡）、milk（牛奶）、bread（面包）、juice（果汁）、apple（苹果）、handbag（手提包）十个单词。

### 在苹果电脑上打开

1. 在仓库页面点绿色 **Code** 按钮，选择 **Download ZIP** 下载。
2. 在“下载”文件夹找到压缩包，双击解压。
3. 打开解压后的文件夹，双击 **index.html**，即可在浏览器练习。也可以右键文件，选择“打开方式”→ Chrome 或 Safari。

手机屏幕布局也已适配；本地 HTML 文件在部分手机文件查看器中无法执行脚本，建议首先在电脑浏览器使用。

### 怎样练习

- 看中文，在输入框拼英文，点击“检查答案”或按 Enter。大小写和首尾空格不影响判断。
- 不会时点“查看答案”。答错或查看答案的单词都会加入错词列表。
- 每题只统计一次。查看答案计入练习题数，不计入独立答对；看过答案后不能在同题重复提交来增加正确题数。
- 点击“下一个单词”，或作答后再次按 Enter 继续。
- 点击“错词重练”，单独复习错词。之后独立答对时，该词移出错词列表；本轮仍会完整练完。
- 今日题数、正确题数、错词和当前练习进度自动保存在当前浏览器，刷新页面也能继续。日期按设备本地日期计算，新的一天重新统计。

### 记录保存说明

数据仅保存在当前设备、当前浏览器的 localStorage，不会上传。请保持文件位置和浏览器一致；移动文件、清除浏览器数据、使用无痕窗口或更换设备，可能使原记录不可用。不同浏览器对本地文件的存储支持有所不同；保存不可用时，页面会提示，仍可临时练习。

整个程序都在 index.html 里，不需要安装 Node.js、Python 或其他软件。
